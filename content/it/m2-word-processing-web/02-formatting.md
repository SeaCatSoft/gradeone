## Lesson

**Formatting** is everything about how a document looks, as distinct from what
it says. It works at three levels — the character, the paragraph and the page —
and knowing which level a feature belongs to is half of understanding it.

### Character formatting

Applies to selected **text**, down to a single letter.

| Feature | Effect |
|---|---|
| **Font** (typeface) | Arial, Times New Roman, Calibri |
| **Font size** | Measured in points; 12 pt is usual for body text |
| **Bold**, *italic*, underline | Emphasis |
| Font colour | The colour of the characters |
| Highlight | A coloured background behind the text |
| Superscript / subscript | x², H₂O |
| Strikethrough | Text struck through |
| Change case | UPPER, lower, Sentence case |
| Character spacing | The gap between letters |

Two conventions worth following: **do not use more than two or three fonts in
one document**, and use **bold** rather than underline for emphasis —
underlining on screen suggests a hyperlink.

### Paragraph formatting

Applies to whole **paragraphs**. You do not need to select the paragraph; the
cursor being inside it is enough.

**Alignment** — left, centre, right, or **justified** (both edges straight).
Body text is usually left-aligned or justified; headings are often centred.

**Indentation** — how far a paragraph sits from the margins. A **first-line
indent** indents only the opening line; a **hanging indent** indents everything
*except* the first line, which is how bulleted lists and bibliographies line
up.

**Line spacing** — the gap between lines within a paragraph: single, 1.5, or
double. Double spacing is often asked for in work that will be marked by hand.

**Space before and after** — the gap between paragraphs. This is the right way
to separate paragraphs; pressing Enter twice is the wrong way, because the
spacing cannot then be changed consistently.

**Bullets and numbering** — unordered lists take bullets, ordered ones take
numbers. Automatic numbering renumbers itself when an item is inserted, which
is why it beats typing the numbers.

**Tabs** — stops the cursor jumps to, used to line columns up. Set tab stops
rather than pressing the space bar: spaces do not align reliably, because most
fonts give different characters different widths.

**Borders and shading** — a box or background behind a paragraph.

**Drop cap** — an enlarged first letter dropping into the paragraph.

### Page formatting

Applies to the whole document, or to a **section** of it.

**Margins** — the blank space around the edges of the page.

**Orientation** — **portrait** (tall) or **landscape** (wide). A wide table is
the usual reason for landscape.

**Paper size** — A4, Letter and so on.

**Columns** — text flowing in two or more columns, as in a newsletter.

**Headers and footers** — text repeated at the top or bottom of every page:
the document title, the author, the date, and **page numbers**, which the word
processor numbers automatically.

**Page breaks** — forcing the text to continue on a new page. Insert a page
break rather than pressing Enter repeatedly; added text will otherwise push
everything out of place.

**Watermark** — faint text or an image behind the page, such as `DRAFT`.

**Page borders** — a frame around the whole page.

### Which level does a feature belong to?

This is the distinction most worth having clear:

| Level | Applies to | Examples |
|---|---|---|
| Character | Selected text | Font, size, bold, colour |
| Paragraph | Whole paragraphs | Alignment, indents, line spacing, bullets |
| Page | The document or section | Margins, orientation, columns, headers |

A quick test: if you can apply it to a single word, it is character formatting.
If it affects the whole paragraph no matter what you selected — alignment,
line spacing — it is paragraph formatting.

### Styles

A **style** is a named set of formatting applied in one action. `Heading 1`
might mean Arial, 16 pt, bold, dark blue, 12 pt of space above.

Styles are the feature students skip and professionals rely on, for four
reasons:

**Consistency.** Every heading formatted with the same style looks identical,
however long the document.

**One place to change.** Change the style and every paragraph using it changes
at once. Formatting forty headings by hand means correcting forty headings by
hand.

**They build the table of contents.** A word processor finds headings by
looking for the heading *styles*. Text made large and bold by hand looks like a
heading and is not one, so it will not appear in an automatic contents list.
This is the single most practical reason to use them, and it comes up again in
the table-of-contents lesson.

**Navigation and accessibility.** Styled headings let you jump about the
document, and screen readers use them to announce its structure.

### The format painter

The **format painter** copies formatting from one piece of text to another
without changing the words: select formatted text, click the painter, then
select the text to change. Double-clicking the painter keeps it on for several
applications.

It is a convenient shortcut. For anything repeated more than a few times, a
style is better — the format painter copies the appearance but creates no link,
so a later change still has to be made everywhere.

### Choosing appropriate formatting

The objective says *appropriate* formatting, and examination questions ask you
to justify choices:

- **Landscape** orientation for a wide table.
- **Justified** text for a formal report; left-aligned for a letter.
- **Double spacing** where a marker needs room to write.
- **Columns** for a newsletter.
- **Headers and footers** for page numbers in a long document.
- **Bullets** for a list of items with no order; **numbers** where order or
  sequence matters.

The general principle: formatting exists to make a document easier to read.
Anything that draws attention to itself rather than to the content — five
fonts, a page border on a business letter, colour used decoratively — is
working against that.

## Flashcards

### 4.2 | Name the three levels at which formatting is applied.
**Character** (selected text), **paragraph** (whole paragraphs) and **page**
(the document or section).

### 4.2 | Give four examples of character formatting.
Any four: font, font size, bold, italic, underline, font colour, highlight,
superscript, subscript, strikethrough, change case.

### 4.2 | Give four examples of paragraph formatting.
Any four: alignment, indentation, line spacing, space before or after, bullets
and numbering, tabs, borders and shading.

### 4.2 | What is justified alignment?
Text with both the left and right edges straight, achieved by adjusting the
spaces between words.

### 4.2 | What is a hanging indent, and where is it used?
Everything except the first line is indented. It is how bulleted lists and
bibliography entries line up.

### 4.2 | Why set space before or after a paragraph rather than pressing Enter twice?
The spacing is part of the paragraph's formatting, so it can be changed
consistently everywhere. Blank lines cannot.

### 4.2 | Why use tab stops rather than the space bar to line up columns?
Most fonts give characters different widths, so spaces do not align reliably. A
tab stop is a fixed position.

### 4.2 | When would landscape orientation be chosen?
When the content is wider than it is tall — most often a wide table or chart.

### 4.2 | What is a header or footer used for?
Text repeated at the top or bottom of every page — the title, author, date and
automatic page numbers.

### 4.2 | What is a style?
A named set of formatting applied in one action, such as `Heading 1`.

### 4.2 | Give three reasons for using styles rather than formatting by hand.
Any three: every item formatted alike stays consistent; changing the style
changes every paragraph using it; the automatic table of contents is built from
heading styles; styled headings aid navigation and screen readers.

### 4.2 | Why will text made large and bold by hand not appear in an automatic table of contents?
The word processor finds headings by looking for heading **styles**, not for
text that merely looks like a heading.

### 4.2 | What does the format painter do, and what is its limitation?
It copies formatting from one piece of text to another. It creates no link, so
a later change must still be made everywhere — a style is better for anything
repeated.

### 4.2 | When are bullets preferred to numbers?
Bullets for a list with no particular order; numbers where the order or
sequence matters.

## Questions

### 4.2 | mcq | 1 mark | difficulty 1
Which of the following is an example of **paragraph** formatting?

- A. Bold
- B. Font size
- C. Line spacing
- D. Superscript

**Answer:** C

**Working:** Line spacing applies to a whole paragraph. The others apply to
selected characters and can be used on a single letter.

### 4.2 | mcq | 1 mark | difficulty 2
Text in which both the left and right edges are straight is said to be

- A. centred
- B. justified
- C. indented
- D. right-aligned

**Answer:** B

**Working:** Justification adjusts the spacing between words so that both
margins line up.

### 4.2 | mcq | 1 mark | difficulty 2
A report contains a table that is much wider than it is tall. The most suitable
change is to

- A. reduce the font size to 6 pt
- B. change the page orientation to landscape
- C. add a page border
- D. use double line spacing

**Answer:** B

**Working:** Landscape gives the page more width, which is what the table
needs. Shrinking the font to 6 pt would fit the table and make it unreadable.

### 4.2 | mcq | 1 mark | difficulty 3
A student formats every heading by selecting it and setting Arial 16 pt bold.
The teacher then asks for all headings to be dark blue. What is the
consequence of not having used styles?

- A. The headings cannot be changed at all
- B. Every heading must be found and changed individually
- C. The document must be retyped
- D. The change happens automatically

**Answer:** B

**Working:** Formatting applied by hand creates no link between the headings.
With a style, changing the style definition would have changed every heading at
once.

### 4.2 | mcq | 1 mark | difficulty 3
Which feature should be used to make a new chapter begin at the top of a fresh
page?

- A. Pressing Enter until the text moves over
- B. Inserting a page break
- C. Increasing the top margin
- D. Adding a header

**Answer:** B

**Working:** A page break holds regardless of what is added above it. Repeated
Enters are pushed out of place as soon as the earlier text changes.

### 4.2 | structured | 10 marks | difficulty 3
A student is producing a six-page project report containing headings, several
wide tables, and a bibliography.

(a) State the level of formatting — character, paragraph or page — to which
each of the following belongs:

(i) font colour **(1 mark)**

(ii) margins **(1 mark)**

(iii) line spacing **(1 mark)**

(b) Name the formatting feature the student should use for each requirement,
and give a reason:

(i) the report title is to appear at the top of every page **(2 marks)**

(ii) the wide tables must fit across the page **(2 marks)**

(iii) each bibliography entry's second and later lines are to be indented
**(1 mark)**

(c) State **two** advantages of formatting the headings with a heading style
rather than by hand. **(2 marks)**

**Answer:** (a)(i) Character. (ii) Page. (iii) Paragraph.
(b)(i) 1 mark — a header; 1 mark — text placed in a header is repeated
automatically at the top of every page.
(ii) 1 mark — landscape orientation (accept: a section in landscape);
1 mark — it gives the page greater width, so the table fits without shrinking
the text.
(iii) A hanging indent — 1 mark.
(c) 1 mark each, any two: all headings stay consistent; changing the style
changes every heading at once; an automatic table of contents can be generated
from them; the document can be navigated by heading; screen readers can
announce the structure.

**Working:** (b)(ii) Note that only the pages with tables need to be landscape.
Placing them in their own **section** allows the orientation to change part-way
through a document.

(c) The table of contents point is the one students most often miss, and it
matters here because a six-page report with headings is exactly the case where
a contents list is expected.
