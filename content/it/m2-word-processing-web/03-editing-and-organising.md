## Lesson

Formatting decides how a document looks. **Editing** decides what it contains
and how it is arranged — moving material about, finding things, and imposing a
structure on a document too long to hold in your head.

### Moving and copying text

**Cut and paste** moves text; **copy and paste** duplicates it. **Drag and
drop** does the same thing by hand for a short move.

**Undo** reverses the last action, and can usually be repeated back through
many. **Redo** reverses the undo. Undo is the reason it is safe to experiment,
and knowing it exists changes how you work.

### Find and replace

**Find** locates every occurrence of a word. **Replace** swaps it for another,
one at a time or all at once.

As in a spreadsheet, **Replace All** is quick and unforgiving. Replacing `ID`
with `Identification` across a document also rewrites `IDEA` and `video`.
Options that prevent this:

- **Match case** — `IT` but not `it`
- **Find whole words only** — `ID` but not inside `video`
- Stepping through with **Replace** rather than **Replace All**

Find can also search for **formatting** — every italic phrase — and for special
characters such as paragraph marks, which is how you tidy a document pasted
from elsewhere.

### Breaks

A **page break** forces what follows onto a new page.

A **section break** divides the document into parts that can be formatted
independently — different orientation, different margins, different headers,
different page numbering. This is how one report holds portrait text and a
landscape table.

The difference in one line: a page break changes **where** text continues; a
section break changes **how** the following part may be formatted.

A **column break** moves the text to the top of the next column.

### Tables

A **table** organises information in rows and columns. Beyond obvious tabular
data, tables are used to line up material that must not drift — a form, a
letterhead, side-by-side blocks.

Rows and columns can be inserted and deleted, cells **merged** into one or
**split** into several, and borders and shading applied. Text inside a cell can
be aligned horizontally and vertically.

Two features worth knowing: a table can be **sorted** on a chosen column, and a
long table can be set to **repeat its header row** on every page, which is a
table's version of a header.

### Structuring a long document

**Heading styles** do more than make headings look alike. They give the
document a structure the word processor understands: `Heading 1` for chapters,
`Heading 2` for sections within them, `Heading 3` below that.

Once headings are styled:

- the **navigation pane** lists them, and clicking one jumps there;
- whole sections can be **collapsed** to see the shape of the document;
- a section can be **moved** in the navigation pane, and its text moves with
  it;
- an automatic **table of contents** can be generated;
- **outline view** shows the hierarchy alone, with the body text hidden.

For a six-page project this is convenient. For a sixty-page one it is the
difference between a document you can work on and one you cannot.

### Other organising features

**Bookmarks** — named places you can jump to.

**Cross-references** — a reference to another part of the document, such as
"see Table 3 on page 12", which updates itself if the table moves.

**Captions** — numbered labels for figures and tables, which renumber
themselves when one is inserted.

**Footnotes and endnotes** — notes at the foot of the page or the end of the
document, numbered automatically.

**Comments** — notes attached to text but not part of it; covered with the
review features.

What these have in common is that the word processor maintains them. A
cross-reference typed by hand as "see page 12" is wrong the moment a paragraph
is added above it; an automatic one renumbers itself.

### Spelling as you edit

A word processor marks suspected spelling and grammar errors as you type.
Checking them properly is a review feature and belongs to the next lesson, but
one caution applies while editing: the checker compares words against a
dictionary, so a correctly spelt **wrong word** — `form` for `from`, `their`
for `there` — passes without comment.

### Choosing the right feature

| To do this | Use |
|---|---|
| Change a word everywhere | Find and Replace |
| Start a chapter on a new page | Page break |
| Change orientation part-way through | Section break |
| Line up columns of information | A table |
| Move a whole section elsewhere | Navigation pane with heading styles |
| Refer to another page | A cross-reference |
| Number figures | Captions |

## Flashcards

### 4.3 | What is the difference between cut and copy?
**Cut** removes the text and places it on the clipboard; **copy** leaves the
original in place.

### 4.3 | Give two options that make Replace All safer.
**Match case** and **find whole words only**. Stepping through with Replace
rather than Replace All is safer still.

### 4.3 | Why can Replace All be dangerous?
It replaces the text inside longer words too — replacing `ID` with
`Identification` would also rewrite `video`.

### 4.3 | What is the difference between a page break and a section break?
A **page break** moves the following text to a new page. A **section break**
divides the document into parts that can be formatted independently — different
orientation, margins, headers or page numbering.

> Hint: which one lets one report hold both portrait and landscape pages?

### 4.3 | Name three things that can be done to cells in a table.
Any three: insert or delete rows and columns; merge cells into one; split a
cell into several; apply borders and shading; align text within a cell.

### 4.3 | What does "repeat header row" do in a long table?
Prints the table's heading row again at the top of every page the table
continues onto.

### 4.3 | Name four things heading styles make possible in a long document.
Any four: navigating by the navigation pane; collapsing sections; moving a
whole section with its text; generating an automatic table of contents; outline
view.

### 4.3 | What is a cross-reference, and why is it better than typing "see page 12"?
A reference to another part of the document that updates itself. A typed page
number is wrong as soon as anything above it changes.

### 4.3 | What is a caption?
A numbered label for a figure or table, which renumbers itself automatically
when another is inserted.

### 4.3 | Why does a spell checker not catch every mistake?
It compares words against a dictionary, so a correctly spelt but wrong word —
`form` for `from` — is accepted.

## Questions

### 4.3 | mcq | 1 mark | difficulty 2
Which feature should be used to change the page orientation for only part of a
document?

- A. Page break
- B. Section break
- C. Column break
- D. Line break

**Answer:** B

**Working:** A section break divides the document into independently
formattable parts. A page break only moves text to a new page and carries no
formatting of its own.

### 4.3 | mcq | 1 mark | difficulty 2
A student uses Replace All to change `ID` to `Identification` and finds that
`video` has become `videntification`. Which option would have prevented this?

- A. Match case
- B. Find whole words only
- C. Use wildcards
- D. Replace backwards

**Answer:** B

**Working:** The problem is that `ID` was found inside a longer word. Matching
whole words only restricts replacement to `ID` standing alone.

### 4.3 | mcq | 1 mark | difficulty 3
In a long report, which feature allows a whole section and its text to be moved
to a different position in one action?

- A. Cut and paste from the navigation pane, with heading styles applied
- B. The format painter
- C. A watermark
- D. A footnote

**Answer:** A

**Working:** Heading styles give the document a structure the navigation pane
can manipulate: dragging a heading there moves everything beneath it. Without
styles, the text must be selected by hand.

### 4.3 | mcq | 1 mark | difficulty 3
A report says "the results are shown in Table 3 on page 12". Two pages of text
are then added before it. If the reference was typed by hand, it

- A. updates automatically
- B. is now wrong, and must be corrected by hand
- C. produces an error message
- D. is removed from the document

**Answer:** B

**Working:** Typed text is not maintained by anything. A cross-reference
inserted as a field would have updated itself.

### 4.3 | mcq | 1 mark | difficulty 2
A spell checker accepts the sentence "The results were taken form the table."
This is because

- A. the checker is switched off
- B. `form` is a correctly spelt word
- C. the sentence is too short to check
- D. grammar checking cannot be used with tables

**Answer:** B

**Working:** The checker compares each word against a dictionary and `form` is
in it. Only proofreading catches a correctly spelt wrong word.

### 4.3 | structured | 9 marks | difficulty 3
A student is preparing a 30-page project containing chapters, several figures,
and one wide table that must be printed sideways.

(a) Name the feature that should be used to:

(i) begin each chapter on a new page **(1 mark)**

(ii) print the wide table in landscape while the rest stays portrait
**(1 mark)**

(iii) number the figures so they renumber when one is inserted **(1 mark)**

(b) Explain **two** benefits the student gains by applying heading styles to
the chapter titles. **(4 marks)**

(c) The student wants to change every occurrence of `computer` to `device`.
State **one** precaution to take, and give a reason. **(2 marks)**

**Answer:** (a)(i) A page break. (ii) A section break (before and after the
table), with that section set to landscape. (iii) Captions.
(b) 2 marks for each of two benefits, one for naming and one for explaining:
an automatic table of contents can be generated, because the word processor
finds headings by their style; the document can be navigated or reorganised
from the navigation pane, where moving a heading moves its text with it; all
chapter titles stay consistent, and changing the style changes them all at
once; sections can be collapsed to see the document's shape.
(c) 1 mark — use "find whole words only" or step through with Replace rather
than Replace All; 1 mark — otherwise the text inside longer words is replaced
too, and any occurrence where `computer` should stay is changed without being
seen.

**Working:** (a)(ii) Two section breaks are needed, one either side, or the
whole of the rest of the document changes orientation as well.

(b) Each benefit needs a reason for the second mark. "It looks neater" is not
a benefit of styles specifically — formatting by hand looks identical.
