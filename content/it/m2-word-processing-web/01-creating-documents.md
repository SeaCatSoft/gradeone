## Lesson

Few documents are typed from nothing. A report pulls a table from a
spreadsheet, a photograph from a camera, a paragraph from a web page and a
chart from somebody else's file.

A **word processor** is software for producing text documents — Microsoft Word,
Google Docs, LibreOffice Writer, Apple Pages. Bringing outside material into
one cleanly is the subject of this lesson.

### Where content comes from

| Source | How it arrives |
|---|---|
| Typed directly | The keyboard |
| Another document | Copy and paste, or Insert → File |
| A spreadsheet | Copy and paste, or insert as an object |
| A database | A report exported, or through mail merge |
| A web page | Copy and paste — with care |
| A camera or scanner | Insert → Picture |
| Printed text | A scanner plus **OCR** |
| Clip art or stock images | Insert → Online pictures |
| Speech | Voice recognition (speech-to-text) |

**OCR** — optical character recognition — deserves a note. A scanner produces
a *picture* of a page, in which the words cannot be searched or edited. OCR
software examines that picture and converts the shapes back into text. It is
how a printed document becomes an editable one, and it is never quite perfect,
so OCR output must be proofread.

### Copy, cut and paste

**Copy** leaves the original where it is; **cut** removes it. Both place the
material on the **clipboard**, a temporary store, and **paste** puts it where
the cursor is.

The clipboard holds the last thing placed on it, and holds it across programs —
which is what lets you copy from a spreadsheet and paste into a document.

### Paste Special

Pasting from another program carries the original's formatting with it, which
is why a document assembled by pasting often looks like a ransom note — three
fonts, four sizes, coloured text from a web page.

**Paste Special** lets you choose what arrives:

| Option | Result |
|---|---|
| Keep source formatting | Looks as it did in the original |
| Merge formatting | Adapts to the surrounding text |
| **Keep text only** (unformatted) | Plain text, takes your document's style |
| Picture | An image — cannot be edited as text |
| Paste **link** | Stays connected to the source file |

For text taken from a web page, **keep text only** is almost always right. It
strips the colours, fonts and hidden styling and leaves the words.

### Linking and embedding

When a spreadsheet table or chart is brought in, there are two ways to hold it,
and the difference is examined.

**Embedding** places a copy inside your document. The document is
self-contained and can be sent to anyone. But it is a **copy**: change the
spreadsheet afterwards and the document still shows the old figures.

**Linking** stores only a reference to the original file. The document shows
the current contents, so correcting the spreadsheet corrects the report. But
the link breaks if the spreadsheet is moved, renamed or not sent along with the
document.

| | Embedded | Linked |
|---|---|---|
| Data stored | Inside the document | In the original file |
| Updates when source changes | No | Yes |
| File size | Larger | Smaller |
| Safe to email on its own | Yes | No — link breaks |

Choose **linking** for figures that will keep changing and a document you keep
alongside them; **embedding** for a finished document that must travel.

### Inserting objects

Beyond text and pictures, most word processors will insert **tables**,
**charts**, **shapes**, **text boxes**, **symbols** (©, ±, é), **equations**,
and **SmartArt**-style diagrams.

An inserted picture can then be resized, cropped, wrapped with text around it,
and given a caption. Two points worth knowing: resize a picture by dragging a
**corner** handle, since a side handle stretches it out of proportion; and text
**wrapping** decides whether the picture sits in the line of text, or the text
flows around it.

### Using other people's material

Content taken from elsewhere usually belongs to someone. Three rules:

**Acknowledge the source.** Quote and cite. Passing off someone else's work as
your own is **plagiarism**, and in an SBA it is treated seriously.

**Check you are allowed to use it.** Most images on the web are covered by
copyright. Look for material offered under a licence that permits reuse, or
produce your own.

**Check it is accurate.** Anyone may publish anything on the web. Prefer a
source that names its author and its date, and confirm a surprising fact
somewhere else before repeating it.

### Saving and file formats

| Format | Use |
|---|---|
| `.docx` | The word processor's own format, keeps everything |
| `.pdf` | Fixed layout, looks the same everywhere, not easily edited |
| `.txt` | Plain text, no formatting at all |
| `.rtf` | Basic formatting, readable by most word processors |
| `.html` | A web page |

Export to **PDF** when a document must be read and printed exactly as designed
and not altered — an invoice, a finished report, a résumé being sent to an
employer.

## Flashcards

### 4.1 | What is a word processor?
Software for producing text documents — for example Microsoft Word, Google Docs
or LibreOffice Writer.

### 4.1 | Name four sources of content for a document.
Any four: typed text; another document; a spreadsheet; a database; a web page;
a camera or scanner; clip art; speech through voice recognition.

### 4.1 | What is OCR and what is it for?
**Optical character recognition** — software that converts a scanned picture of
a page into editable, searchable text. Its output must be proofread.

### 4.1 | What is the difference between cut and copy?
**Cut** removes the original; **copy** leaves it in place. Both put the
material on the clipboard.

### 4.1 | What is the clipboard?
A temporary store holding the last item cut or copied, shared between programs
so material can be moved from one to another.

### 4.1 | Why use "keep text only" when pasting from a web page?
It strips the source's fonts, colours and hidden styling, leaving plain words
that take on your document's formatting.

### 4.1 | Distinguish between linking and embedding an object.
**Embedding** stores a copy inside the document, which does not update.
**Linking** stores a reference to the original file, so the document always
shows the current contents.

> Hint: which one survives being emailed on its own?

### 4.1 | Give one advantage and one disadvantage of linking a spreadsheet chart into a report.
Advantage: the report updates automatically when the spreadsheet changes.
Disadvantage: the link breaks if the spreadsheet is moved, renamed or not sent
with the document.

### 4.1 | Why resize a picture using a corner handle rather than a side handle?
A corner handle keeps the picture in proportion. A side handle stretches it.

### 4.1 | What is plagiarism?
Presenting someone else's work as your own. Material taken from other sources
must be acknowledged.

### 4.1 | When should a document be saved as a PDF?
When it must be read and printed exactly as designed and not easily altered —
an invoice, a finished report, a résumé.

## Questions

### 4.1 | mcq | 1 mark | difficulty 2
Which technology converts a scanned image of a printed page into editable text?

- A. OMR
- B. OCR
- C. MICR
- D. OLE

**Answer:** B

**Working:** Optical character recognition examines the shapes in the scanned
picture and converts them back into characters. Without it, a scan is only an
image.

### 4.1 | mcq | 1 mark | difficulty 2
A student copies several paragraphs from a web page into a report, and they
arrive in a different font and colour from the rest. The best way to avoid this
is to use

- A. Paste Special → Keep text only
- B. Paste Special → Picture
- C. Cut instead of copy
- D. Insert → Object

**Answer:** A

**Working:** Pasting as unformatted text strips the source's styling, so the
text takes on the document's own formatting. Pasting as a picture would make it
uneditable.

### 4.1 | mcq | 1 mark | difficulty 3
A sales chart is **embedded** in a report. The spreadsheet it came from is then
corrected. What does the report show?

- A. The corrected figures
- B. The original figures
- C. An error message
- D. A broken link symbol

**Answer:** B

**Working:** Embedding stores a copy, which does not follow the original.
Linking would have shown the corrected figures — at the cost of breaking if the
spreadsheet is moved.

### 4.1 | mcq | 1 mark | difficulty 3
A manager will email a report to head office as a single attachment, and the
figures in it are final. The chart from the spreadsheet should therefore be

- A. linked, so it stays up to date
- B. embedded, so the document is self-contained
- C. pasted as plain text
- D. left out and described in words

**Answer:** B

**Working:** A linked object depends on the spreadsheet file, which is not
being sent, so the link would break. The figures are final, so there is nothing
to gain from linking.

### 4.1 | mcq | 1 mark | difficulty 2
Which file format would be chosen so that a document looks the same on every
computer and cannot easily be edited?

- A. `.txt`
- B. `.rtf`
- C. `.pdf`
- D. `.docx`

**Answer:** C

**Working:** PDF fixes the layout and is not readily editable, which is why
finished documents are distributed in it.

### 4.1 | structured | 9 marks | difficulty 3
A student is preparing a project report. It must contain typed text, a
photograph taken on a phone, a table of results from a spreadsheet, and a
paragraph quoted from a website.

(a) State how each of the following would be brought into the document:

(i) the photograph **(1 mark)**

(ii) the table of results **(1 mark)**

(b) The spreadsheet results are still being collected and will change. State
whether the table should be linked or embedded, and give a reason. **(2 marks)**

(c) The quoted paragraph arrives in a different font and colour. State the
feature used to avoid this and explain how it works. **(2 marks)**

(d) State **two** things the student must do when using material taken from a
website. **(2 marks)**

(e) The finished report must be emailed to the teacher exactly as laid out.
State a suitable file format. **(1 mark)**

**Answer:** (a)(i) Insert → Picture from a file (accept: transfer from the
phone, then insert). (ii) Copy from the spreadsheet and paste into the
document (accept: Insert → Object).
(b) 1 mark — linked; 1 mark — the document then shows the current figures, so
the report updates automatically when the spreadsheet is corrected.
(c) 1 mark — Paste Special, choosing "keep text only" / unformatted text;
1 mark — it strips the source's formatting so the text takes on the document's
own style.
(d) 1 mark each, any two: acknowledge the source / cite it, to avoid
plagiarism; check that copyright permits its use; check that the information is
accurate and the source reliable.
(e) PDF — 1 mark.

**Working:** (b) The key phrase in the question is "will change". Linking is
right here even though it is fragile, because the whole point is that the
report should follow the data. Once the figures are final and the report is
being sent out, embedding becomes the better choice — as part (e) hints.
