## Lesson

A **relation** is a rule that links members of one set to members of another.
"Is the capital of", "is a factor of" and "is 3 more than" are all relations.

### The vocabulary

- The **domain** is the set of **inputs** — the starting values.
- The **codomain** is the set the outputs are drawn from.
- The **range** is the set of outputs actually **used**. It's part of the
  codomain, but not always all of it.
- Each linked pair is written as an **ordered pair** $(x, y)$: input first,
  output second.

### Four ways to show a relation

Take the relation "is a factor of", from $\{2, 3, 5\}$ to $\{6, 10, 15\}$.

**1. As ordered pairs:**

$$\{(2, 6),\ (2, 10),\ (3, 6),\ (3, 15),\ (5, 10),\ (5, 15)\}$$

**2. As an arrow diagram:** two ovals, the domain on the left and the codomain
on the right, with an arrow from each input to each output it's linked to.

**3. As a graph:** plot each ordered pair as a point, with inputs on the
horizontal axis.

**4. As a rule or equation:** for number relations, such as $y = 2x + 1$.

### Types of relation

Look at how many arrows leave each input and arrive at each output:

| Type | What happens | Example |
|---|---|---|
| **One-to-one** | each input has one output, and each output comes from one input | $x \to x + 1$ |
| **Many-to-one** | several inputs share the same output | $x \to x^2$ (both 2 and $-2$ go to 4) |
| **One-to-many** | an input has more than one output | "is a factor of" (2 goes to 6 and to 10) |
| **Many-to-many** | both happen | the factor relation above: 6 also comes from 2 and 3 |

These types matter because they decide whether a relation is a **function** —
the subject of the next lesson.

## Flashcards

### 3.1 | What is the domain of a relation?
The set of **inputs**.

### 3.1 | What is the difference between the codomain and the range?
The codomain is the set outputs may come from. The range is the set of outputs
actually **used**.

### 3.2 | Name four ways to represent a relation.
Ordered pairs, an arrow diagram, a graph, and a rule or equation.

### 3.1 | What type of relation is $x \to x^2$ on $\{-2, -1, 1, 2\}$?
**Many-to-one.** For example, both $-2$ and $2$ map to 4.

### 3.1 | In an ordered pair $(x, y)$, which is the input?
$x$, the first element.

## Questions

### 3.1 | mcq | 1 mark | difficulty 1
The relation $\{(1, 3), (2, 5), (3, 7), (4, 9)\}$ has domain

- A. $\{3, 5, 7, 9\}$
- B. $\{1, 2, 3, 4\}$
- C. $\{1, 2, 3, 4, 5, 7, 9\}$
- D. $\{4\}$

**Answer:** B

**Working:** The domain is the set of first elements (the inputs). A is the
range.

### 3.1 | mcq | 1 mark | difficulty 2
Which type of relation is shown by $\{(1, 5), (2, 5), (3, 5)\}$?

- A. One-to-one
- B. One-to-many
- C. Many-to-one
- D. Many-to-many

**Answer:** C

**Working:** Three different inputs all map to the same output, 5.

### 3.2 | mcq | 1 mark | difficulty 2
The relation $y = 2x - 1$ has domain $\{0, 1, 2, 3\}$. What is its range?

- A. $\{-1, 1, 3, 5\}$
- B. $\{0, 1, 2, 3\}$
- C. $\{1, 3, 5, 7\}$
- D. $\{-1, 0, 1, 2\}$

**Answer:** A

**Working:** $2(0) - 1 = -1$, $2(1) - 1 = 1$, $2(2) - 1 = 3$, $2(3) - 1 = 5$.

### 3.2 | structured | 4 marks | difficulty 2
The relation "is half of" maps $A = \{2, 3, 5\}$ to $B = \{4, 6, 8, 10\}$.

(a) List the relation as a set of ordered pairs. **(2 marks)**

(b) State the range of the relation. **(1 mark)**

(c) What type of relation is it? **(1 mark)**

**Answer:** (a) $\{(2, 4), (3, 6), (5, 10)\}$ (b) $\{4, 6, 10\}$ (c) One-to-one

**Working:** (b) 8 is in the codomain $B$ but isn't used, so it's not in the
range.

(c) Each input has exactly one output, and no output is shared.
